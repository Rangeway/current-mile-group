# Current Mile Group

The public one-page website for Current Mile Group at
[currentmile.com](https://currentmile.com).

## Prerequisites

- Node.js `>=22.13.0`

## Local development

```bash
npm install
npm run dev
npm run build
npm test
```

The production build is a static export in `dist/client`.

## Deployment

Pushing `main` runs the GitHub Actions build and publishes `dist/client` to the
`deploy-dist` branch. The existing Rangeway VPS deployment timer pulls that
branch into `/var/www/current-mile-group`, where nginx serves `currentmile.com`
and `www.currentmile.com` over HTTPS.

Do not edit `deploy-dist` directly; it is generated by GitHub Actions.
